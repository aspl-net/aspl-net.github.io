# ASPL project page

Static project page for *Active-Set Projection Layers for Hard-Constrained Neural Networks*.
Single `index.html` (no build step), figures in `figs/`, paper in `paper.pdf`.
Served by GitHub Pages from the `main` branch root.

Numbers in the Results charts come from the paper: Table `tab:qp-results` (QP),
Table `tab:ik-amortized` (IK) and Figure `fig:fm` (flow matching).
