One Small Backward Solve

Provable Guarantees

Exact Constraints, Real Robots
Flat accuracy on QPs while Πnet degrades by 1000×; IK task error below 10−10 on real Vega-1 and G1 logs.

Projection layers enforce hard constraints exactly, but their gradient degrades as more constraints become tight. ASPL differentiates through the active manifold: the backward pass is one small solve on the tight and curved directions. It works with any forward solver, with finite-time identification and a local O(1/T) training rate. It improves accuracy or cost on QPs, motion planning and real-robot IK, and enforces constraints in flow matching.

How ASPL Works

A backbone maps the context x to a prediction; the layer returns the nearest feasible point y on the face where some constraints are tight.

Theorem 2

Tight set fixed early

Within a radius ρ of the solver's limit, every projection lies on the same tight face, so the active set is identified in finitely many iterations, before the solver converges.

Geometry

Free, blocked, curved

At y, some directions are free and the Jacobian is the identity there. Only the blocked directions (tight constraints) and the curved ones (smooth boundaries) carry information for the gradient.

Theorem 1

One small solve

The implicit-differentiation system is block lower-triangular, so the backward pass is a single dN×dN solve instead of d×d. On flat faces the Jacobian is the tangent projector.

Quick Start

One library, with the robotics applications as separate packages that use it

# Clone from Hugging Face
git clone https://huggingface.co/ASLP-Net/ASPL
cd ASPL

# Install the library (plus optional reference solvers / JAX CUDA plugins)
pip install -e aspl
pip install -e "aspl[solvers]"
pip install -e "aspl[cuda]"

# Check the layer without any data: task residual ~1e-14, QP objective to 1e-8,
# and an adjoint that matches central finite differences
cd applications/ik && python test_layer.py
ASPL/
├── aspl/                  # the library: polyhedral, second-order-cone and general prox-set projections
│   ├── aspl/algorithms/   # forward (face identification) + exact reduced backward
│   └── aspl/problems/     # parametric QP, SOCP, MPC: data generation + training CLIs
└── applications/
    ├── ik/                # chunk-level differentiable IK on Vega-1 and G1 logs
    ├── motion_planning/   # maze (graph of convex sets) and multi-robot
    └── flow_matching/     # hard-constrained flow-matching policies (RoboTwin 2.0)
